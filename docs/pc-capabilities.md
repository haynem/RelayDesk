# PC版の要件と現状（2026-10-27）

PC版を先に仕上げる。Androidの開発・最終配布物の更新は保留。

## 画面の構成

- 最初の画面は、未読・要確認の連絡を推定優先度順に表示する。元サービスで未読と判明した項目と、未読状態を取得できない項目を区別する。
- 優先度は低・中・高。上下ボタンは1段階ずつ変える。上限・下限を超えない。推定へ戻す操作も用意する。調整は端末内に保存し、同期後も保持する。
- 一覧から会話を選んで返信案を作成できる。実送信は対応アダプターのみ、宛先・本文の確認と承認を経て行う。
- 「アプリ画面」で元のWebサービスを表示する。対応サービスではアプリ内に埋め込み、別ウィンドウでも開ける。LINEはインストール済み公式アプリ、Gmailは公式ブラウザー画面を使用する。
- 元画面の操作では既読などが発生し得るため、開く前に説明する。統合一覧内のローカル確認操作では元サービスへ既読を送らない。
- ウィンドウの閉じる操作で通知領域へ移動し同期を継続。終了は通知領域メニューから行う。
- PCの新着通知は本文・相手名・アカウント名をOSへ出さず件数のみ通知する。初回履歴・既知の本文・自分の発言・取得失敗・確認済みは除外。通知する優先度を選択できる。OS上の表示・音は実環境での最終確認が必要。
- 入力中の返信文を暗号化して自動保存。会話の切り替え・画面更新・再読み込み後に復元する。承認待ちの返信案へ保存すると入力中の文はクリアする。
- ChatGPT共有はアカウント全体／選んだ会話だけを選択できる。MCPの全閲覧・検索・要確認一覧・返信案保存に同じ範囲を適用。既定は共有オフ。
- 同期は最大3アカウントを並行処理し、同じアカウントの二重取得を避ける。停止後の遅い応答は保管庫へ反映しない。

## 実接続と未完了

|サービス|確認済み|残る主な制約|
|---|---|---|
|Instagram|実DMの取得・保存・表示|全履歴、正確な未読取得、統合送信、添付操作など|
|LINE|実会話取得、未読情報、連絡先APIのフォールバックで160件の送信者名を実解決|一部の過去E2EE本文が復号不可、実送信未検証|
|Gmail|実IMAP読み取り、未読、複数アカウント用表示名、追加の過去200通を実読み取り（最新ページとの重複0）、本人承認済みの自分宛て1通のSMTP送信と実受信|OAuth、受信箱以外のフォルダー。全履歴の走査完了は未確認|
|Messenger|実初期会話・平文本文を新しい読み取りヘルパーで取得|E2EE本文、完全履歴、統合送信|
|Slack|本人ログイン後、実20会話・118メッセージを取得。権限不足の分離・取得制限の待機・複数ワークスペースの識別|全履歴、送信・添付などの実検証。未読情報は実20会話で取得し、95件のメッセージで送信者名を解決|
|Discord|公式画面、Bot用アダプター|個人DMの統合取得未対応。本人トークンの取得・保存は行わない|

元のWeb画面が開けることだけで全機能の網羅とは扱わない。通話・画面共有・外部リンク・添付などは個別に検証が必要。通常ChatGPTのリモート接続も未完成。

## 検証

自動テスト48件、架空データのElectron基本UI10項目、優先一覧など13フロー（未送信返信案の編集・取消も追加）、埋め込みサービス画面8項目に合格。通知領域テストで閉じる際の非表示・生存・終了復帰を確認。本人が宛先・件名・本文を画面で承認した自分宛てテスト1通のみ実送信し、送信成功とIMAPでの実受信を確認。送信IDと受信メールのMessage-IDを端末内で照合した。私的本文のスクリーンショットは作成していない。

Messenger読み取りヘルパーはWindows x64、macOS arm64／x64向けのコンパイルに成功。Mac用の検証ZIPには対応ソースとハッシュを照合できるヘルパーを同梱した。本人がMacでDMG生成、アプリ起動、LINE認証、会話一覧と本文の表示まで確認した。Mac上のMessengerヘルパー実行、ほかのサービス、送信、通知、再起動・スリープ復帰は別途検証が必要。

Slackのチャンネルを開くURL形式は[Slack公式ヘルプ](https://slack.com/intl/en-gb/help/articles/221769328-Locate-your-Slack-URL-or-ID)を参照。実アカウントでの会話ジャンプの検証は別途必要。

release内の0.2.1 EXE・旧MacソースZIP・旧APKは今回のUI修正より古い。最新PC版の完成品として扱わない。RelayDesk-Mac-bundled-20261027.zipから本人のMacでDMGを生成し、起動とLINE閲覧を確認済み（本人報告）。認証情報や保管庫をZIPへ同梱していない。最新Windows EXEの更新と両OSの全機能検収は残る。
