# サービス別の実装状況

2026-10-27。**今回追加した機能は動作未検証です。** 実取得確認は追加前の履歴を指します。

|サービス|以前の実確認|今回のコード|制約|
|---|---|---|---|
|LINE|QR、実本文・未読・送信者名。Macでも本人が本文確認|履歴、名簿、引用、E2EE画像・動画・音声・ファイル送信、取得・保存、リアクション、取消、既読モード|一部の過去E2EE、旧ルーム等、固有操作|
|Instagram|実DM取得・暗号化保存・復元・検索|段階的な一覧取得、履歴、本文・引用・メディア送信、取得先が分かった添付の保存、既読モード|非公開GraphQL変更、未取得メディア形式、編集・取消・リアクションと名簿取得を追加。いずれも今回実通信は未検証|
|Messenger|新規ヘルパーによる初期一覧・平文|平文とE2EEの履歴、添付、引用、送信、編集、取消、リアクション、既読。E2EE端末登録、暗号化DB、本人PINでの履歴復元|今回のE2EE通信・復元は未検証。拡張形式などの網羅は継続|
|Slack|実会話・本文・未読・名前|履歴、返信スレッド、名簿、引用スレッド返信、現行アップロード、添付保存、編集・削除・リアクション、既読|権限、管理者制限、取得制限、全スレッドの常時追跡|
|メール|Gmail IMAP、追加履歴、承認済み自己宛て1通の実送受信|選択フォルダー、フォルダー別履歴、UID差分、添付、CC/BCC、全員返信、引用チェーン、Google/Microsoft OAuth、Seenの分離|OAuth登録が別途必要。Gmail設定権限を追加許可すると、承認付きで送信元フィルターを作成・取消する処理を追加。迷惑メール・ブロック・サーバー削除は開発継続|
|Discord|公式画面とBot用コード|Bot履歴・引用・添付・自分の編集削除・リアクション、公式OAuth/RPCの指定会話本文取り込み処理|**本人個人DMの統合は未達成**。全DM列挙・全履歴・個人送信が必要。Botや公式画面・指定会話の取り込みだけで代替完了としない|

添付は1個25MiB、送信案合計100MiB・最大10個。元サービスの上限が小さい場合があります。メール原本は35MiBまで。HTMLメールや外部トラッキング画像を自動実行しません。ラスタ画像・音声・動画はblob URLでプレビューし、それ以外は本人が保存先を選びます。

初期設定はnever。on-sendは送信確認後だけ、alwaysは本人が会話を開いた際だけ、対応APIへ既読を送ります。既読の失敗で送信済みを未送信に戻しません。相手側の表示は今回未検証です。

公式画面は補助経路です。共通データや固有機能の完全性の証拠とは扱いません。[Discord接続条件](discord-connection-decision.md)を参照してください。
