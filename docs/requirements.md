# 要件定義・初版

依頼書の最終要件は維持する。本リリースは段階的な実装であり、未対応を要件から削除したものではない。

## 優先順位

1. Sendy本体・保存領域に変更を加えず、非公開の別リポジトリを作る。
2. Windowsアプリを起動し、1サービスの実メッセージを共通受信箱へ表示する。
3. 閲覧と既読更新を分離し、横断検索・複数アカウント・承認待ち下書きを提供する。
4. Androidの公開APIによる通知学習の実装と実機検証。
5. 各サービスの直接接続・送信機能・通常ChatGPT向け認証付きMCP。
6. macOS・Androidの統合受信箱・iOS・端末同期・統合通知・履歴の完全同期。

## 実アカウントの検証手順

本人がアプリ内で認証する。受信・本文取得・検索・再同期の重複排除を確認し、結果には本文を記録せず件数と時刻だけを残す。既読は本人のテスト用会話について、相手側の協力または本人が管理する別テストアカウントで確認する。通常の会話を勝手にテスト送信に使わない。

送信機能は、宛先・本文・対象サービス・一回限りの承認を具体的に確認してから実装検証する。MCPの返信案作成権限に送信承認を含めない。削除・ブロック・迷惑メール報告・受信箱からの除外・ミュートは別操作として設計する。

## 維持する最終要件

LINE、Instagram、Messenger、Slack、メール、Discordの会話・履歴・参加者・添付・引用・スレッド・リアクション・編集・取消。安全な既読モード `on-send / never / always`。差分同期・認証復旧・複数アカウント。ChatGPTの読み取り・返信案作成・明示承認。Androidの計測に基づく重要度判定・提案と取消・アプリ別許可・履歴削除。Phase A/B切替と重複通知抑制。Windows/macOS/Android/iOSの基本チャット機能。PC停止時のキャッシュ表示と将来の常時稼働先への移行。
