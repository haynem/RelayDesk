## 残項目

- Discord本人個人DMの統合。適用可能な承認済みアプリ等の方式が必要で、未完成条件を維持する。
- Messenger E2EEは端末登録・永続鍵保護・履歴復元・送受信・操作・名簿のコードを追加。実通信と拡張形式の網羅は別途必要。
- LINEの一部過去E2EE本文、各サービス固有機能の完全な網羅、プロバイダーの制限を超えた完全履歴。
- Google/MicrosoftのOAuthアプリ登録、通常ChatGPTの利用権限・本人の接続操作。設定コードを書いても外部の登録を済ませたことにはしない。
- Gmail送信元フィルターは追加OAuth権限・個別承認・取消・結果不明時の照合を実装。迷惑メール報告／ブロック／受信箱除外を同一操作にしない。通常の整理提案はローカル通知だけで、Gmail設定へ進むには別ボタンと具体的な承認が必要。
- WindowsからAndroidの他アプリ通知リスナーを置き換えることはしない。Android/iOSは現在のPC優先から分離。
- 今回追加した機能の実通信・UI・相手側既読・通常ChatGPTからの動作検証。
