# RelayDesk — PC版・実装先行ビルド

2026-10-27。個人利用向けの非公開アプリです。本人の「動作テストを挟まずWindowsで実装を進める」という指示に従って追加開発しています。**今回の機能は実装・コンパイルの段階で、6サービスの全要件完成版とは扱いません。**

今回より前には、WindowsでInstagram・LINE・Messengerの平文・Gmail・Slackの実取得と、本人承認済みの自分宛てメール1通の実送受信を確認しました。Macでは本人がDMG生成・起動・LINE本文表示を確認しています。これらは今回の追加機能の検証結果ではありません。

## Windowsで使う

今回の変更はソース実装中です。releaseにある過去の実行ファイルへ今回の変更が反映済みとは扱いません。新しい完成版の配布ファイルはまだ作成していません。既存アプリは通知領域のメニューから終了してから新版を起動します。保存先は引き続き %APPDATA%\\RelayDesk-private\\ です。

- 要確認一覧：低・中・高の推定優先度。上下は1段階ずつ変更します。
- 会話：本文、添付プレビュー・保存、引用、過去履歴、対応する編集・取消・リアクション。
- 承認待ち：宛先・本文・引用元・添付を確認して送信。結果不明の操作を自動再実行しません。
- メール：新規作成、CC/BCC、全員に返信、フォルダー選択、追加履歴。既存のGmailアプリパスワードも使用できます。
- 元アプリ画面：各サービスの固有機能の補助経路。閲覧で既読が発生し得ます。通話・共有は元サービスとOSの対応範囲に従います。
- 通知管理：PC通知、実際のアプリ内閲覧・返信・後回しによる学習、理由付き整理提案と取り消し。更新したインストール版の初回起動でWindowsログイン時起動を有効にするコードを追加しました。オフにした設定は保持します。1分同期・段階的な自動再接続・暗号化した取得位置からの再開、任意のスリープ抑止にも対応します。
- ChatGPT連携：アカウント／選択会話の共有と下書き権限、OAuth、任意の簡易トンネル・固定Cloudflareトンネルの自動復帰。実接続は未確認です。
- 機能の対応状況：サービス別のコード対応範囲と残項目。

認証は公式画面かアプリ内だけで行います。秘密の文字列をチャットへ送る必要はありません。同じ本人として再認証すると会話・下書きを保持します。既読の初期設定はnever。対応接続ではon-send／alwaysも選択できます。相手側での既読を絶対に防げるという実証はしていません。

## 残っていること

**Discord本人の全個人DMの統合はまだ未完成です。** MessengerのE2EE端末登録・暗号化鍵DB・履歴復元・送受信・編集取消等はコードを追加しましたが、今回の実通信確認はしていません。 Botや公式画面だけで完成扱いにしません。一部のLINE過去本文にも復号できないものがあります。元サービスのすべての固有機能を統合画面で網羅した状態ではありません。

メールOAuthには本人側のGoogle／Microsoftアプリ登録が必要です。Gmailの送信元フィルター（受信箱からの自動除外・取消）は、別途設定権限と操作承認を必要とする処理を追加しました。迷惑メール報告やブロックとは分けています。通常の整理提案の承認ではRelayDesk自身の通知だけを変更します。

Android・iOSはPC版優先のため今回更新していません。Windowsのアプリ内学習とAndroidの他アプリ通知収集はOSごとの別処理です。元アプリの通知をすべてオフにする段階には達していません。

## 保存と接続

state.encに認証・会話・下書き・学習・共有設定をAES-256-GCMで保存し、assets内に添付を個別に暗号化します。鍵はElectron safeStorageでOSに保護させます。Messengerのネイティブ鍵DBはAdiantum VFSでDB・ジャーナルを暗号化し、保護されたマスター鍵からアカウント別に導出した鍵を使用します。Gitやログへ個人データを入れません。鍵を失うと復元できません。バックアップ移行機能は未実装です。

通常画面のAPIは127.0.0.1のランダムポートと起動ごとの秘密値で保護します。公開用AI受付は別ポートでOAuthと共有範囲を検査します。簡易トンネルは画面で承認して開始するまで動かしません。今回は外部公開も課金契約も実施していません。

## ソースからビルド

Node.js 24以上とnpm。WindowsはStart-RelayDesk.cmd、Macはscripts/Build-macOS.commandが起点です。npm ci --no-fund --no-audit → npm run build → npm run package:win。

MessengerヘルパーにはGo 1.27以上、または対応ソースとSHA-256が一致する同梱バイナリーが必要です。Mac用ソースZIPの方式も維持しています。第三者ライセンスはTHIRD_PARTY_NOTICES.mdとnative/messengerにあります。

npm testはテストを再開する際の既存コマンドです。今回は実行していません。
